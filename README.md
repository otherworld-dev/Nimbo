# Nimbo

A fast, native **Nextcloud desktop sync client for Windows** — two-way sync,
real-time push, on-demand (virtual) files, selective sync, conflicts & version
history, sharing, and deep Windows/Explorer integration.

Website: **https://www.nimbosync.com**

## Download

Grab the latest installer from the [**Releases**](https://github.com/otherworld-dev/Nimbo/releases/latest) page.

Nimbo auto-updates via the Windows App Installer feed once installed:

```
Add-AppxPackage -AppInstallerFile "https://github.com/otherworld-dev/Nimbo/releases/latest/download/Nimbo.appinstaller"
```

> Windows 10/11 x64. The package is signed with a development certificate; the
> bundled installer trusts it for you.
